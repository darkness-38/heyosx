# Conventions

## Languages & Styling
- **Rust**: Uses standard Rust conventions (Snake Case for functions, PascalCase for types). Edtion 2021.
- **Shell Scripts**: Simple Bash/SH scripts for automation. Turkish naming convention for `transTR` utilities.
- **Slint**: Declarative UI syntax with standard Slint layout patterns.

## Development Workflow
- **Cargo**: Used for managing Rust dependencies and building binaries.
- **mkarchiso**: Standard Arch tool for assembling the ISO.
- **Profile Management**: Configuration stored in `profiledef.sh`.

## Naming Conventions
- `heydm-*`: Display manager related scripts/binaries.
- `transTR`: Turkish Translation (System utilities).
- `airootfs`: Standard `archiso` naming for the root overlay.
